Phần tổng hợp nhật ký công việc thực tập (Worklog) trong suốt chương trình **First Cloud AI Journey (FCAJ)**. Quá trình thực tập được triển khai xuyên suốt **9 tuần** (từ ngày **03/06/2026** đến ngày **31/07/2026**), bao gồm các giai đoạn học tập dịch vụ AWS nền tảng, nghiên cứu chuyên sâu các công nghệ Serverless/Security, triển khai dự án thực tế **Serverless Todo/Note Web Application** và hoàn thiện báo cáo.

Dưới đây là tóm tắt tiến độ công việc theo từng tuần:

* **Tuần 1:** [Làm quen với FCAJ, tìm hiểu `tổng quan AWS services, AWS Console & CLI](1.1-week1/)
* **Tuần 2:** [Tìm hiểu Amazon VPC, máy chủ EC2, ghép nhóm chốt đề tài & thực hành Cloud Tools](1.2-week2/)
* **Tuần 3:** [Thực hành Web Serverless với S3/CloudFront, thiết kế UI/UX trên Figma](1.3-week3/)
* **Tuần 4:** [Cơ sở dữ liệu NoSQL Amazon DynamoDB & Quản lý chi phí với AWS Budgets](1.4-week4/)
* **Tuần 5:** [Tính toán Serverless với AWS Lambda & Tạo REST API qua Amazon API Gateway](1.5-week5/)
* **Tuần 6:** [Xác thực người dùng Amazon Cognito & Bảo mật S3 Presigned URL](1.6-week6/)
* **Tuần 7:** [Giám sát với Amazon CloudWatch Logs/Alarms & Soạn thảo Proposal dự án](1.7-week7/)
* **Tuần 8:** [Thực hành Serverless Workshop & Đăng 3 bài Tech Blog lên AWS Study Group](1.8-week8/)
* **Tuần 9:** [Triển khai dự án - Dựng tầng Backend Lambda CRUD & DynamoDB/S3 Storage](1.9-week9/)
