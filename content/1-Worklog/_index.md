This page summarizes the internship worklog throughout the **First Cloud AI Journey (FCAJ)** program. Below is the weekly summary of tasks and achievements:

* **Week 2:** [Exploring Amazon VPC, EC2 instances, team grouping & configuring Cloud Tools](1.2-week2/)
* **Week 3:** [Deploying Serverless Web with S3/CloudFront, designing UI/UX on Figma](1.3-week3/)
* **Week 4:** [Configuring NoSQL Amazon DynamoDB & AWS Budgets cost management](1.4-week4/)
* **Week 5:** [Serverless Compute with AWS Lambda & Creating REST API via Amazon API Gateway](1.5-week5/)
* **Week 6:** [Authenticating users with Amazon Cognito & Enabling S3 Presigned URLs](1.6-week6/)
* **Week 7:** [Managing Amazon CloudWatch Logs/Alarms & Drafting Project Proposal](1.7-week7/)
* **Week 8:** [Executing Serverless Workshop & Publishing 3 Tech Blogs on AWS Study Group](1.8-week8/)
* **Week 9:** [Project Execution - Building Backend Lambda CRUD & DynamoDB/S3 Storage](1.9-week9/)
